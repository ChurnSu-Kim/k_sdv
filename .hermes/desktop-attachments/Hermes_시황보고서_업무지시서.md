# 🎯 Hermes AI Agent 업무지시서
## 일일 주식시황 분석보고서 작성 표준 프로세스 (SOP)

> **작성 목적**: 기존 보고서가 "숫자 나열"에 그치고 매매 판단에 실제로 쓸 수 있는 정보가 부족하다는 피드백에 따라, 정보수집→팩트체크→분석→보고서화 전 과정을 재정의한다.
> **적용 대상**: Hermes AI Agent (매일 09:20 자동 실행)
> **핵심 원칙**: "숫자만 던지지 말고, 그 숫자가 오늘 내 매매에 뭘 의미하는지까지 말하라."

---

## 0. 회장(사용자)의 진짜 의도 — 반드시 먼저 이해할 것

Hermes는 아래 4가지를 매일 보고서 작성 전에 스스로 되묻고 시작해야 한다.

1. **회장은 "뉴스 요약"이 아니라 "오늘 뭘 해야 하는가"에 대한 답을 원한다.**
   - 지수가 몇 %인지가 아니라, "그래서 내 보유종목은 사야 하나 팔아야 하나 버텨야 하나"가 핵심.
2. **회장은 한 장(1 page)으로 오늘 시장 전체를 파악하고 싶어한다.**
   - 스크롤을 여러 번 내려야 하는 나열식 표는 실패다. 정보는 우선순위대로, 위에서 아래로 "중요한 것부터".
3. **회장은 보유종목 섹션을 가장 신뢰한다.** (기존 6번 항목)
   - 이 품질을 시장 전체 섹션에도 동일하게 적용해야 한다: 수량·평단 수준의 구체성을 지수/업종/거시 지표에도 적용하라는 의미.
4. **회장은 데이터가 틀리거나(예: 요일·날짜 꼬임, "데이터 없음" 방치) 출처가 불명확한 것을 매우 싫어한다.**
   - 확인 안 된 숫자는 "추정" 표시, 아예 없으면 항목 자체를 빼거나 왜 없는지 명시.

## 1단계: 정보수집 — "무엇을, 어디서, 어떻게" 모아야 하는가

기존 보고서는 지수 몇 개 + 환율 + 업종 방향성 정도만 수집했다. 아래 8개 카테고리를 **빠짐없이** 수집해야 "매매에 필요한 정보"가 된다.

| # | 카테고리 | 반드시 포함할 세부 데이터 | 기존 보고서 문제점 |
|---|---------|--------------------------|-------------------|
| 1 | 글로벌 마감 | S&P500/나스닥/다우 **종가, 등락률, 등락폭**, 필라델피아반도체지수(SOX), VIX 지수 | 나스닥 "소폭 하락"처럼 숫자 없이 서술만 함 |
| 2 | 국내 지수 (당일 실시간) | KOSPI/KOSDAQ **당일 시가·현재가(또는 종가)·고가·저가·거래대금**, 전일 대비 | 전일(7/24) 데이터를 당일(7/27)인 것처럼 헷갈리게 배치 |
| 3 | 수급 동향 | KOSPI/KOSDAQ **외국인·기관·개인 순매수 상위 5종목**, 프로그램매매 동향 | 완전히 누락 |
| 4 | 환율·금리·원자재 | USD/KRW **단일 확정값**(출처 명시), 한국 10년물 국고채 금리, WTI/브렌트유, 금 시세 | USD/KRW이 두 출처로 갈려 1459~1488 범위로만 제시 → 매매기준 불가 |
| 5 | 업종·테마 등락률 순위 | 당일 **등락률 상위/하위 각 5개 업종**(%), 거래대금 상위 테마 | "▼약세/↔혼조"처럼 방향만 있고 %가 없음 |
| 6 | 개별 종목 기술적 레벨 | 보유종목 + 관심종목의 **당일 현재가, 전일대비 %, 5일/20일/60일 이동평균선 위치, RSI, 직전 지지/저항선** | 보유종목 표에 가격·수량만 있고 기술적 판단 근거 없음 |
| 7 | 경제/이벤트 캘린더 | 오늘~익일 예정된 **국내외 경제지표 발표, 실적발표, FOMC/한은 금통위 일정** | 완전히 누락 → 다음날 변동성 예측 불가 |
| 8 | 암호화폐 | 보유 코인(ETH, XRP, VIRTUAL 등) **실시간 원화 시세**, 전일 대비 %, 김치프리미엄 여부 | "정확 시세 데이터 없음"으로 방치됨 — 이건 수집 실패이지 보고할 내용이 아님 |

**수집 원칙**
- 모든 수치는 **출처(사이트/API명) + 조회 시각(KST)**을 함께 기록한다.
- 동일 지표를 두 출처에서 다르게 얻으면, 더 신뢰도 높은 출처 하나를 기준값으로 채택하고 나머지는 참고용으로만 각주 처리한다. (범위로 얼버무리지 않는다.)
- 데이터를 못 구한 항목은 "데이터 없음"이라고 던지지 말고, ①왜 못 구했는지 ②대체 가능한 근사치가 있는지 ③다음 실행 때 어떻게 보완할지를 1줄로 남긴다.

## 2단계: 팩트체크 — 보고서 작성 전 검증 체크리스트

Hermes는 아래 체크리스트를 통과하지 못한 데이터는 보고서에 넣지 않는다.

- [ ] **날짜 정합성**: 오늘이 실제 개장일인가? 데이터가 "직전 거래일" 것인지 "당일 실시간"인지 표에 명확히 라벨링했는가?
- [ ] **수치 재검증**: 지수/환율/유가는 최소 2개 독립 출처로 교차 확인했는가? 차이가 0.5% 이상이면 재조회했는가?
- [ ] **보유종목 원장 대조**: `data/보유주식_*.md` 최신 파일과 수량·평단이 100% 일치하는가? 중복 계좌 병합 시 가중평단 계산식을 표기했는가?
- [ ] **논리적 일관성**: "유가 하락 → 다우 상승"처럼 인과를 서술했다면, 그 인과가 실제 당일 뉴스로 뒷받침되는가 아니면 추측인가? 추측이면 "추정"이라 표기.
- [ ] **환각 방지**: 실제 조회하지 못한 수치를 그럴듯하게 채워넣지 않았는가? (예: "XRP 1달러대 초반 추정"처럼 실시간 조회 실패를 슬쩍 넘기지 말 것 — 반드시 재시도 후에도 실패하면 "미확인"으로 명시)

## 3단계: 분석 — 숫자를 "매매 판단"으로 바꾸는 단계

수집·검증된 데이터를 아래 4가지 렌즈로 반드시 해석해서 붙인다.

1. **오늘의 시장 국면 정의**: 급락 후 반등 시도 / 박스권 / 추세 지속 / 변동성 확대 중 하나로 명확히 규정.
2. **보유 포트폴리오 영향도 순위**: 오늘 시황 기준으로 "가장 영향받는 보유종목 Top3"를 금액 기준으로 산출 (평가손익 변동폭 큰 순).
3. **업종 로테이션 시그널**: 자금이 어디서 빠져 어디로 가는지 (예: 반도체→방산, 성장주→가치주 등) 1~2문장으로.
4. **오늘의 액션 아이템**: 다음 3개 중 최소 하나를 종목별로 제시한다 — 관찰(홀드), 리스크 관리 필요(손절/비중축소 고려선 명시), 반등 시 매수 후보. *투자 권유가 아닌 "체크포인트 제시" 톤 유지.*

---

## 4단계: 보고서 작성 — "한 장"으로 보이는 포맷 규칙

기존 마크다운 표 나열 방식 대신, 아래 순서와 밀도로 재구성한다.

### 상단 (스크롤 없이 보이는 영역)
1. **오늘의 한줄 요약** (시장 국면 + 핵심 리스크 1개, 총 2문장 이내)
2. **핵심 지표 스냅샷 표** (KOSPI/KOSDAQ 현재가·등락률, USD/KRW 확정값, WTI, VIX — 5개 이내로 압축)
3. **내 포트폴리오 영향 Top3** (금액 변동 기준, 각 1줄 코멘트)

### 중단
4. 업종 등락률 상위/하위 (막대 형태로 시각화 가능하면 Chart.js 활용)
5. 수급 동향 요약 (외국인/기관 순매수 상위 테마)
6. 보유종목 상세표 (기존 6번 항목 형식 유지 — 이 부분은 회장이 만족한 형식이므로 손대지 않음)

### 하단
7. 오늘~내일 이벤트 캘린더 (경제지표/실적/통화정책 일정)
8. 오늘의 액션 아이템 (종목별 체크포인트)
9. 면책 문구

---

## 5. 절대 하지 말아야 할 것 (안티패턴)

- ❌ 방향 화살표(▲▼↔)만 표시하고 수치를 생략하는 것
- ❌ 출처가 다른 두 수치를 범위(~)로 뭉개서 제시하는 것
- ❌ "데이터 없음"이라고만 쓰고 원인/대안 설명 없이 넘어가는 것
- ❌ 날짜·요일이 실제 거래일과 어긋난 채로 표기하는 것
- ❌ 매매 권유로 오인될 수 있는 단정적 문구 ("지금 사세요" 등) — 항상 "체크포인트/참고" 톤 유지
